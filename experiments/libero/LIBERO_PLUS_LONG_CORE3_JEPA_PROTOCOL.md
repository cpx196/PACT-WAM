## Future-video-aligned K=1 baseline (completed)

The corrected control uses the same checkpoint, statistics, task variants, task ordering, seeds, trial count, `sigma_shift=5.0`, future-video generation, and eight-action replan interval as the JEPA treatment:

```text
EVALUATION.visualize_future_video=true

```

With the ranker disabled, `infer_joint` receives no `num_action_candidates` override and therefore uses effective K=1. Results: task 410 = 2/4, task 662 = 0/4, task 457 = 0/4; total **2/12 (16.7%)**. All 12 rollouts include generated-future artifacts. ## JEPA–FastWAM treatment

Use exactly the same checkpoint, task list, seeds, Plus environment, trial count, and task ordering. Change only the policy treatment:

```text
EVALUATION.visualize_future_video=true
EVALUATION.vjepa2_ac.enabled=true
EVALUATION.vjepa2_ac.num_action_candidates=8
EVALUATION.vjepa2_ac.replan_steps=8
EVALUATION.replan_steps=8
```

The selector receives eight action candidates per replan, generated by batched action flow matching. It ranks them against the FastWAM-generated future reference. `replan_steps=8` is required to align the two V-JEPA action-conditioner steps with the predicted future-video interval; it is intentionally different from the original action-only baseline’s `replan_steps=10`.

Use the FP32 V-JEPA2-AC checkpoint configured in `configs/sim_libero.yaml`:

```text
EVALUATION.vjepa2_ac.checkpoint_path=/data/chenpengxu/jepa_wam_assets/vjepa2-ac-vitg.pt
EVALUATION.vjepa2_ac.repo_path=/data/chenpengxu/vjepa2
EVALUATION.vjepa2_ac.dtype=float32
```

## Launch recipe

Use GPUs 2 and 3 unless their ownership/state has changed. Run one seed at a time so each seed directory contains a self-contained configuration, videos, JSON results, and worker logs.

```bash
cd /data/chenpengxu/FastWAM

for seed in 7 17 27 37; do
  env \
    PYTHONPATH=/data/chenpengxu/LIBERO-plus:/data/chenpengxu/FastWAM/src:/data/chenpengxu/jepa_wam_py312 \
    LIBERO_CONFIG_PATH=/data/chenpengxu/JEPA_WAM/.libero_plus_config \
    DIFFSYNTH_MODEL_BASE_PATH=/data/chenpengxu/FastWAM/checkpoints/wan \
    HF_HOME=/data/chenpengxu/hf_home \
    PYOPENGL_PLATFORM=egl MUJOCO_GL=egl \
    CUDA_VISIBLE_DEVICES=2,3 \
    PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
    /data/chenpengxu/conda_envs/HMoE/bin/python experiments/libero/run_libero_manager.py \
      task=libero_uncond_2cam224_1e-4 \
      ckpt=/data/chenpengxu/FastWAM/checkpoints/fastwam_release/libero_uncond_2cam224.pt \
      seed=${seed} \
      EVALUATION.num_trials=1 \
      EVALUATION.output_dir=/data/chenpengxu/FastWAM/evaluate_results/fastwam_jepa_libero_plus_long_core3_20260909/seed_${seed} \
      EVALUATION.sigma_shift=5.0 \
      EVALUATION.dataset_stats_path=/data/chenpengxu/FastWAM/checkpoints/fastwam_release/libero_uncond_2cam224_dataset_stats.json \
      EVALUATION.offload_text_encoder=true \
      EVALUATION.visualize_future_video=true \
      EVALUATION.replan_steps=8 \
      EVALUATION.vjepa2_ac.enabled=true \
      EVALUATION.vjepa2_ac.num_action_candidates=8 \
      EVALUATION.vjepa2_ac.replan_steps=8 \
      MULTIRUN.task_file=/data/chenpengxu/FastWAM/experiments/libero/task_lists/libero_plus_long_robot_init_core3.txt \
      MULTIRUN.num_gpus=2
done
```
